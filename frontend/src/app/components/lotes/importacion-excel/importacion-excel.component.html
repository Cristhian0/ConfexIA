El archivo debe contener las siguientes columnas:

  • Mesa (opcional): Mesa de corte
  • Fecha Corte (opcional): Fecha del corte
  • Referencia (requerido): Código o nombre de la referencia
  • Material (requerido): Código o nombre del material
  • Color (requerido): Código o nombre del color
  • Talla (requerido): Código de la talla
  • Cantidad (requerido): Cantidad programada
  • Observaciones (opcional): Observaciones adicionales
  • Prioridad (opcional): 0=Normal, 1=Alta, 2=Urgente
